# Data Analytics Portfolio

My learning journey in Data Analytics, SQL, Power BI, Python, Cloud and AI.

This portfolio documents my learning through lesson notes, practice exercises, and future analytics projects.

## SQL for Data Science — UC Davis (Coursera)

The `01-sql/sql-for-data-science/` folder contains 13 lesson notes based on my own Portuguese study notes, translated and condensed into English. Practical SQL files are **supplementary examples**, not copied course solutions.

## How to practice

Open `01-sql/sql-for-data-science/sample-database.sql` in SQLite and run the example `.sql` files. Some scripts create objects; run the sample setup first.

## Study principles

Commit genuine changes after study sessions. Do not upload graded Coursera answers, proprietary datasets, or private information.
