# Creating Tables

## Lesson summary
CREATE TABLE defines columns, types and constraints. INSERT INTO adds records. NULL indicates a missing value.

## Source
Personal study notes from the Coursera SQL for Data Science course (UC Davis).

## Reflection
- What did I learn?
  I learned how CREATE TABLE defines a table, its columns, data types, and constraints, and how INSERT INTO adds records. I also reviewed the difference between NULL and an empty string and the role of primary keys.
- What do I still need to practice?
  I still need to practice creating tables and inserting records while specifying the column names and handling NULL values.
