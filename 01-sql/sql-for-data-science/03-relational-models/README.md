# Relational Models

## Lesson summary
Entities have attributes and relationships. Primary keys identify records; foreign keys connect tables. ER diagrams document relationships.

## Source
Personal study notes from the Coursera SQL for Data Science course (UC Davis).

## Reflection
- What did I learn?
  I learned the meaning of entities, attributes, and relationships, including one-to-one, one-to-many, and many-to-many relationships. I also learned how primary keys, foreign keys, and ER diagrams describe connections between tables.
- What do I still need to practice?
  I still need to practice reading ER diagrams and identifying primary and foreign keys in related tables.
