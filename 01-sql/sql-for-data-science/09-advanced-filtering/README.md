# Advanced Filtering

## Lesson summary
IN checks membership, OR combines alternatives, NOT negates conditions. Parentheses make combined logic explicit.

## Source
Personal study notes from the Coursera SQL for Data Science course (UC Davis).

## Reflection
- What did I learn?
  I learned how IN checks for values in a list, OR allows alternative conditions, and NOT excludes matching conditions. I also learned that parentheses matter when combining OR and AND.
- What do I still need to practice?
  I still need to practice combining IN, OR, NOT, and AND while checking that the conditions return the intended records.
