# Sql Comments

## Lesson summary
Use -- for line comments and /* ... */ for block comments. Comments document intent and aid debugging.

## Source
Personal study notes from the Coursera SQL for Data Science course (UC Davis).

## Reflection
- What did I learn?
  I learned how to write single-line comments with -- and block comments with /* ... */. Comments can explain the purpose of a query and help when testing or debugging code.
- What do I still need to practice?
  I still need to practice adding clear, useful comments to my SQL queries without making them unnecessarily long.
