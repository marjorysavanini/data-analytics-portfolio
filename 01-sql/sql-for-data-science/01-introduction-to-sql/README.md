# Introduction To Sql

## Lesson summary
SQL is a declarative language for working with relational databases. Data analysts retrieve and explore information; DBAs manage access, security, and infrastructure.

## Source
Personal study notes from the Coursera SQL for Data Science course (UC Davis).

## Reflection
- What did I learn?
  I learned what SQL means, how it is used to retrieve, insert, and update data, and how data scientists use it differently from database administrators. I also learned that SQL syntax can vary between database systems.
- What do I still need to practice?
  I still need to practice writing basic SQL queries and recognizing syntax differences between database systems.
