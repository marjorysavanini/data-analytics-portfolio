# Order By

## Lesson summary
ORDER BY sorts query results by one or more columns, using ASC or DESC.

## Source
Personal study notes from the Coursera SQL for Data Science course (UC Davis).

## Reflection
- What did I learn?
  I learned how ORDER BY sorts query results in ascending (ASC) or descending (DESC) order. I also learned that results can be sorted by multiple columns and that ORDER BY is placed at the end of a query.
- What do I still need to practice?
  I still need to practice sorting by multiple columns and selecting the correct sort direction for each column.
