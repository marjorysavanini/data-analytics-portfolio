# Wildcards Like

## Lesson summary
LIKE matches text patterns. % matches any sequence of characters.

## Source
Personal study notes from the Coursera SQL for Data Science course (UC Davis).

## Reflection
- What did I learn?
  I learned how LIKE and the % wildcard can find text that starts with, ends with, or contains a pattern. I also learned that wildcard searches may affect query performance.
- What do I still need to practice?
  I still need to practice writing LIKE patterns and choosing between pattern matching and more direct comparisons.
