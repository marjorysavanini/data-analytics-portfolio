# Aggregate Functions

## Lesson summary
AVG, COUNT, MIN, MAX and SUM summarize data. COUNT(DISTINCT column) counts unique non-NULL values.

## Source
Personal study notes from the Coursera SQL for Data Science course (UC Davis).

## Reflection
- What did I learn?
  I learned how AVG, COUNT, MIN, MAX, and SUM summarize values in a column. I also reviewed how DISTINCT can remove duplicates and how COUNT(DISTINCT column) counts unique values.
- What do I still need to practice?
  I still need to practice choosing the appropriate aggregate function, understanding how NULL values are treated, and combining aggregate functions in queries.
