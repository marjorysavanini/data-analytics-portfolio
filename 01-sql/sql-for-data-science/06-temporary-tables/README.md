# Temporary Tables

## Lesson summary
Temporary tables support intermediate analysis and typically exist only for a database session. Syntax varies by database.

## Source
Personal study notes from the Coursera SQL for Data Science course (UC Davis).

## Reflection
- What did I learn?
  I learned that temporary tables can store intermediate subsets of data and are generally removed when the database session ends. I also learned that their syntax can vary between database systems.
- What do I still need to practice?
  I still need to practice creating temporary tables and checking the syntax for the database system I am using.
