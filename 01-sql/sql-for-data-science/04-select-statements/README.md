# Select Statements

## Lesson summary
SELECT chooses columns, FROM identifies a table, and LIMIT restricts returned rows.

## Source
Personal study notes from the Coursera SQL for Data Science course (UC Davis).

## Reflection
- What did I learn?
  I learned how SELECT specifies the columns to retrieve, FROM identifies the source table, and the asterisk (*) selects all columns. I also learned how LIMIT restricts the number of returned rows.
- What do I still need to practice?
  I still need to practice writing SELECT queries with specific columns and using LIMIT to inspect data.
